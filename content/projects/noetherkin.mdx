Noetherkin is an open-source, agent-agnostic apprenticeship protocol and CLI for learning software engineering by working inside real codebases instead of tutorials. A trusted local CLI owns every canonical record, while 21 portable Agent Skills, onboarding, task assignment, teaching, peer and team-lead review, debugging, incident response, performance and promotion review, mentor the learner through Claude Code or Codex without ever silently writing state on their behalf. Learners work either against real open-source projects pulled from an 87-project, 34-track catalog, or against first-party "forge" specifications built from an empty directory for early E0–E2 work. Progress is evidence-based rather than point-based: an E0–E5 competency ladder advances only from attributed, verified records of what was actually demonstrated, with every assistance request and review tracked alongside the task it belongs to. Released under Apache 2.0 at wire protocol 3.0 (v0.2.0), with generic, Codex, and Claude Code capability adapters.
